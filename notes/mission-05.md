# Mission 5 – GROUP BY

## 🎯 Objective
Learn to summarize data separately for each group using `GROUP BY` with aggregate functions.

## 🧠 Key Learnings

- `GROUP BY` creates one result row for each group.
- Aggregate functions calculate values within each group.
- `GROUP BY` can be combined with `COUNT()`, `AVG()`, `SUM()`, `MIN()`, and `MAX()`.
- `ORDER BY` can sort aggregated results.

## 💡 Professional Tip
Before writing a grouped query, ask: **"What should one row in my result represent?"**

## ⚠️ Common Mistake
`GROUP BY` groups rows; it does not automatically sort them. Use `ORDER BY` when sorting is required.
