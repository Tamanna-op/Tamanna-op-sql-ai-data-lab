# Mission 7 – INNER JOIN

## 🎯 Objective
Learn to combine related data from multiple tables using `INNER JOIN`.

## 🧠 Key Learnings

- `JOIN` combines related rows from tables.
- Primary keys uniquely identify rows.
- Foreign keys connect related tables.
- `ON` defines the relationship between tables.
- `WHERE` filters the joined results.
- `INNER JOIN` returns only rows with a match in both tables.

## 💡 Professional Tip
Before writing a JOIN, identify:
1. Which tables contain the required data?
2. Which columns connect them?

## ⚠️ Common Mistakes
- Joining unrelated columns.
- Confusing `ON` with `WHERE`.
- Using `==` instead of `=`.
- Using double quotes for string values.
