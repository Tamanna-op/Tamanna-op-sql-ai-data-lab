# Mission 3 – Sorting & Aliases

## 🎯 Objective
Learn to organize query results using `ORDER BY` and improve readability using column aliases (`AS`).

## 🧠 Key Learnings

- `ORDER BY` sorts query results.
- `ASC` sorts in ascending order (default).
- `DESC` sorts in descending order.
- Multiple columns can be used for sorting.
- `AS` gives columns meaningful names in the output.

## 💡 Tips

- Sort reports in a way that helps the reader.
- Use aliases to make reports more readable.

## ⚠️ Mistakes

- Forgetting that `WHERE` is applied before `ORDER BY`.
