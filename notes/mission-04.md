# Mission 4 – Aggregate Functions

## 🎯 Objective
Learn to summarize data using aggregate functions.

## 🧠 Key Learnings

- `COUNT()` → number of rows/values
- `SUM()` → total
- `AVG()` → average
- `MAX()` → highest value
- `MIN()` → lowest value
- `WHERE` can filter rows before aggregation.

## 💡 Professional Tip
Think: filter the relevant rows first, then calculate the required metric.

## ⚠️ Common Mistake
Don't confuse row-level filtering with filtering aggregated results. We'll learn the latter with `GROUP BY`/`HAVING`.
